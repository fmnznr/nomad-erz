# Gewässer & Talsperren

## Flusssystem

Fast der gesamte Erzgebirgskreis entwässert nach **Norden zur Mulde und Elbe**.

```
Zwönitz ──┐
Würschnitz┴─► Chemnitz ──► Zwickauer Mulde ──► Mulde ──► Elbe
Zwickauer Mulde ◄── Schwarzwasser und viele Bäche des Westerzgebirges
Zschopau ◄── Sehma, Pöhlbach, Preßnitz, Wilisch, Flöha ──► Freiberger Mulde ──► Mulde
```

| Fluss / Bach | Verlauf (Auswahl) |
|---|---|
| **Zwönitz** | Quellgebiet südlich von Zwönitz → Zwönitz → Thalheim → Burkhardtsdorf → Chemnitz |
| **Würschnitz** | Raum Stollberg → Jahnsdorf → Chemnitz |
| **Zwickauer Mulde** | Vogtland → Eibenstock (Talsperre) → Aue → Zwickau |
| **Schwarzwasser** | Johanngeorgenstadt → Schwarzenberg → Aue |
| **Zschopau** | Fichtelberg → Wolkenstein → Zschopau → Mittelsachsen |
| **Pöhlbach / Sehma / Preßnitz** | Zuflüsse der Zschopau aus dem oberen Erzgebirge |
| **Flöha** | Tschechien → Olbernhau → Flöha |

## Talsperren und Teiche (Auswahl)

| Gewässer | Nutzung | Hinweis |
|---|---|---|
| **Talsperre Eibenstock** | **Größte Trinkwassertalsperre Sachsens** | Baden, Boote und Angeln im Trinkwasserschutzgebiet verboten |
| **Talsperre Sosa** | Trinkwasser | Rundweg |
| **Talsperre Carlsfeld** | Trinkwasser | Eine der höchstgelegenen Talsperren Deutschlands |
| **Talsperre Cranzahl** | Trinkwasser | – |
| **Talsperre Preßnitz** | Trinkwasser | Bei Jöhstadt |
| **Greifenbachstauweiher** | Badesee | Bei Geyer/Ehrenfriedersdorf, historischer Bergbau-Teich |
| **Filzteich** | Badesee | Bei Schneeberg, historischer Kunstteich (Bergbau) |

Trinkwassertalsperren sind **Schutzgebiete**: Betretungsregeln vor Ort beachten.

## Kunstgräben und Bergbauwasser

Viele **Kunstteiche und Kunstgräben** stammen aus dem Bergbau. Sie trieben Wasserräder an. Wasser aus Stollen-Mundlöchern ist **kein Trinkwasser** → [Trinkwasser](../notfall/trinkwasser.md), [Altbergbau](../notfall/bergbau-gefahren.md).

## Baden

- Freibäder und ausgewiesene Badestellen bevorzugen. Talsperren sind bis auf Ausnahmen gesperrt.
- Bergseen sind auch im Sommer kalt (Kälteschock). Nicht erhitzt hineinspringen.
- Nicht in Stauwehre und Wehranlagen schwimmen (Walzen, Unterströmung).
